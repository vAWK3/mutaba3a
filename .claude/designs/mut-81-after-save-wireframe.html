5. The states nobody has specified yet

Back-dated save lands on page 3. Both lists sort by date descending. Press Show and you arrive on page 1 without the row, with no second message. Eng review flagged this as the one silent failure (task T2). There is no designed state for "we took you there and it still is not visible".
Focus. ADR-044 §6 returns focus to the trigger when a drawer unmounts. If the trigger was a row button in a list that just re-sorted, where does focus land? MUT-82's plan has a whole decision on this (its D12). MUT-81's says nothing.
