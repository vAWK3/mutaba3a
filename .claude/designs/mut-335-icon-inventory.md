# MUT-335 — Canonical icon inventory (pointer)

The canonical, cross-platform icon inventory for MUT-335 (Gamification epic,
MUT-334) lives in the mutaba3a-flutter repo:

`mutaba3a-flutter/mutaba3a/.claude/designs/mut-335-icon-inventory.md`

Half of that inventory's input is this repo's web icon audit (the `src/components/icons/*`
shared set, the per-file duplicated inline SVGs, and the hosted-portal/landing
mini-sets), so this pointer exists to make it discoverable from mini-crm
without duplicating — and risking drift from — the full table.

Follows the MUT-103 precedent of keeping a design brief in whichever repo's
`.claude/designs/` a decision most concerns, with a cross-reference where a
change spans both.
