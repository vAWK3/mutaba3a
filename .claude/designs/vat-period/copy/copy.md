# Copy (minimal, Arabic first). The app writes this; the art carries no words.

Levantine month names: كانون الثاني، شباط، آذار، نيسان، أيار، حزيران، تموز، آب، أيلول، تشرين الأول، تشرين الثاني، كانون الأول.

| Where | Arabic | English |
|---|---|---|
| State: waiting | بانتظار العميل | Waiting for client |
| State: client done | أرسل العميل | Client sent |
| State: confirmed | مؤكَّد | Confirmed |
| State: more needed | مطلوب المزيد | More needed |
| Client home group title | ضريبة القيمة المضافة · كانون الثاني – شباط | VAT · Jan – Feb |
| Client home due line | 23 آذار | Mar 23 |
| Client primary action | تم | Done |
| Sheet / confirm heading | كل الإيصالات أُرسلت؟ | All receipts sent? |
| After Done (client) | بانتظار المحاسب | Waiting for your accountant |
| After confirm (client) | مؤكَّد من المحاسب | Confirmed by your accountant |
| After ask (client) | يطلب المحاسب المزيد | Your accountant needs more |
| Accountant actions | تأكيد · اطلب المزيد | Confirm · Ask for more |
| Note label | ملاحظة | Note |
| Period control | فترة الضريبة: كل شهرين · شهرياً · سنوياً · بدون | VAT period: Every 2 months · Monthly · Yearly · None |
| Unset period chip | فترة الضريبة | VAT period |
| Desk empty (all confirmed) | الكل مؤكَّد | All confirmed |

Yearly clients show no due date until the statutory date is confirmed.
Mail copy is written in the server (`email/templates/copy.ts`) and is not part of this design.
